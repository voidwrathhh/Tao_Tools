# sertool - 串口终端工具

## 简介
sertool 是 tao_tools 工具链中的串口通信工具，提供串口扫描、连接和数据收发功能。

## 版本
v2.3.0

## 功能
- [x] 扫描并列出系统所有可用串口（含 USB VID/PID、设备描述）
- [x] TUI 界面连接串口，实时显示接收数据（可滚动）
- [x] 专用输入框发送数据，收发分离不干扰
- [x] 断线自动检测 + 每 2 秒重连
- [x] 连接状态实时提示（绿色/红色状态栏）
- [x] ANSI 颜色解析与显示（支持 30-37/90-97 标准色、粗体）
- [x] 鼠标滚轮滚动支持
- [x] 滚动位置独立保持，新数据不干扰已滚动位置
- [x] 默认波特率 115200（USB CDC ACM 设备波特率无关，可连接后 Ctrl+B 切换）
- [x] TUI 内切换波特率（Ctrl+B）
- [x] HEX/文本显示模式切换（Ctrl+H）
- [x] HEX/文本发送模式切换（Ctrl+S，输入十六进制字节发送）
- [x] TUI 内断开/重连串口（Ctrl+D，不退出界面）
- [x] 回车发送/换行模式切换（Ctrl+E，Enter 发数据或换行）
- [x] 追加 \\r\\n 开关（Ctrl+L，控制发送时是否追加换行）
- [ ] 串口参数配置（数据位、停止位、校验位）
- [ ] 日志保存到文件

## 安装

```bash
# 从源码安装（项目根目录或 sertool 目录下执行）
cargo install --path .

# 验证安装
sertool --version
```

安装后可在终端中直接使用 `sertool` 命令。卸载执行 `cargo uninstall sertool`。

## 使用方法

### 列出串口
```bash
# 全局安装后
sertool list

# 或开发模式下
cargo run -- list
```

### 连接串口
```bash
sertool connect <端口名> [波特率]

# 默认波特率 115200
sertool connect COM3
sertool connect /dev/ttyUSB0
# 指定波特率
sertool connect COM3 9600
```

### 交互操作
连接成功后进入 TUI 界面：
- **上方区域**：实时显示设备串口发出的数据（支持 ANSI 颜色 / HEX 模式）
- **下方输入框**：打字输入，回车发送到设备
- **状态栏**：显示连接状态（绿色已连接 / 红色已断开）
- **快捷键**：
  - `↑` / `↓`：滚动查看历史数据
  - `PgUp` / `PgDn`：快速翻页
  - `鼠标滚轮`：滚动历史数据
  - `Enter`：发送输入框内容
  - `Ctrl+B`：切换波特率（在常见波特率列表中循环）
  - `Ctrl+H`：切换 HEX / 文本显示模式
  - `Ctrl+S`：切换 HEX / 文本发送模式（HEX 发送时输入 "FF A0 01" 发送原始字节）
  - `Ctrl+D`：断开 / 重连串口（不退出 TUI）
  - `Ctrl+E`：切换回车发送 / 回车换行
  - `Ctrl+L`：切换发送时追加 / 不追加 `\r\n`
  - `Ctrl+Enter`：强制发送（回车换行模式下使用）
  - `Esc` 或 `Ctrl+C`：退出
- **波特率**：`connect <端口>` 不带波特率时默认为 115200（USB CDC ACM 设备波特率不影响数据传输，可在 TUI 中用 Ctrl+B 切换）
- **断线重连**：设备断开或拔插后自动检测，每 2 秒尝试重连

### 交互演示

```
┌─ COM7 @ 115200bps ────────────────┐  ← 绿框=已连接 / 红框=断开
│  I (708) esp_image: segment 4...  │
│  I (3762) TEST_AI: >>> [2]...     │  ← 设备输出（↑↓滚动）
│  <<< hello                        │  ← 发送回显
│                                    │
├─ 发送 ────────────────────────────┤
│ > hello world                     │  ← 专用输入框
├────────────────────────────────────┤
│ ✓ 已连接 COM7 @ 115200bps  ↑↓滚动  │  ← 状态栏
└────────────────────────────────────┘
```

## 更新历史

### v2.3.0
- 移除：波特率自动检测（USB CDC ACM 设备上波特率设置无效，检测总是误判）
- 变更：`connect <端口>` 不指定波特率时默认 115200
- 新增：回车发送/换行模式切换（Ctrl+E）
- 新增：追加 \\r\\n 开关（Ctrl+L，控制文本发送时是否追加换行）
- 新增：Ctrl+Enter 强制发送（回车换行模式下使用）
- 改进：连接态下 Ctrl+B 提示先断开，防止误操作
- 改进：输入框标题显示当前 Enter 模式

### v2.2.0
- 新增：TUI 内断开/重连串口（Ctrl+D，不退出界面），用户断开时不自动重连
- 改进：自动重连逻辑区分异常断开与用户主动断开

### v2.1.0
- 新增：波特率自动检测（`connect` 不带波特率时自动尝试常见波特率）
- 新增：TUI 内 Ctrl+B 切换波特率，实时重连
- 新增：HEX / 文本显示模式切换（Ctrl+H）
- 新增：HEX / 文本发送模式切换（Ctrl+S，输入十六进制字节发送）
- 新增：HEX 输入解析（支持 "FF A0 01" 或 "FFA001" 格式）
- 改进：输出窗口标题显示当前模式和波特率

### v2.0.1
- 修复：鼠标滚轮在未启用鼠标捕获时无效
- 修复：新数据到达时滚动位置被强制重置到底部
- 修复：滚动到顶部后继续上划导致底部行消失的问题
- 改进：滚动位置独立保持，不随新数据变化

### v2.0.0
- 重构：完整 TUI 界面，数据区与输入区分离
- 新增：断线自动检测 + 每 2 秒重连
- 新增：↑↓ 滚动历史数据
- 新增：PgUp / PgDn 快速翻页
- 新增：连接状态实时显示（绿/红）
- 新增：Ctrl+C 和 Esc 均可退出
- 移除：ctrlc 依赖，改为 crossterm 事件循环

### v1.1.0
- 新增：发送数据本地回显（`<<< ` 前缀）
- 新增：输入提示符（`>>> `）
- 改进：串口读取兼容 ESP32 CDC-ACM 驱动
- 改进：自动设置 DTR 使 ESP32 退出复位状态

### v1.0.0
- 初始版本，支持串口扫描、连接、数据收发
