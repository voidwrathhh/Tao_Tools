# sertool - 串口终端工具

## 简介
sertool 是 tao_tools 工具链中的串口通信工具，提供串口扫描、连接和数据收发功能。

## 版本
v2.4.1

## 功能
- [x] 扫描并列出系统所有可用串口（含 USB VID/PID、设备描述）
- [x] TUI 界面连接串口，实时显示接收数据（可滚动）
- [x] 专用输入框发送数据，收发分离不干扰
- [x] 断线自动检测 + 每 2 秒重连
- [x] 连接状态实时提示（绿色/红色状态栏）
- [x] ANSI 颜色解析与显示（支持 30-37/90-97 标准色、粗体）
- [x] 鼠标滚轮滚动支持
- [x] 滚动位置独立保持，新数据不干扰已滚动位置
- [x] 默认波特率 115200（USB CDC ACM 设备波特率无关，可连接后 Ctrl+B 切换）
- [x] TUI 内切换波特率（Ctrl+B）
- [x] HEX/文本显示模式切换（Ctrl+H）
- [x] HEX/文本发送模式切换（Ctrl+S，输入十六进制字节发送）
- [x] TUI 内断开/重连串口（Ctrl+D，不退出界面）
- [x] 回车发送/换行模式切换（Ctrl+E，Enter 发数据或换行）
- [x] 追加 \\r\\n 开关（Ctrl+L，控制发送时是否追加换行）
- [x] `sertool settings` 独立设置界面（默认波特率、显示/发送模式、回车发送、追加换行），配置持久化
- [x] 配置记忆（`~/.tao_tools/sertool/config.ini`：上次端口、波特率、各开关），`connect` 未指定波特率时取配置值
- [x] 接收管线加固：跨块增量 UTF-8 解码（1KB 读块切断多字节字符也不出 `�`）
- [x] 接收管线加固：无换行数据在读超时（50ms）自动整块吐出，超 8KB 强制断行，最后一个不完整行也可见
- [x] HEX 显示按行拆分，每行带 `0x%04x` 跨块累计地址偏移
- [x] 状态栏显示本次连接累计接收字节数（RX）
- [x] 发送失败不再静默：红色错误提示 + 保留输入内容便于重发

## 安装

```bash
# 在 Tools/ 目录下执行
cargo install --path sertool

# 或在仓库根目录执行
cargo install --path Tools/sertool

# 验证安装
sertool --version
```

安装后可在终端中直接使用 `sertool` 命令。卸载执行 `cargo uninstall sertool`。

## 使用方法

### 列出串口
```bash
# 全局安装后
sertool list

# 或开发模式下
cargo run -- list
```

### 连接串口
```bash
sertool connect <端口名> [波特率]

# 不带波特率时取配置值（默认 115200）
sertool connect COM3
sertool connect /dev/ttyUSB0
# 指定波特率
sertool connect COM3 9600
```

### 设置界面
```bash
sertool settings
```

TUI 设置面板，可修改默认波特率、接收/发送 HEX 模式、回车即发送、发送追加 `\r\n`：

- `↑` / `↓`（或 `j` / `k`）：选择设置项
- `←` / `→`（或 `Enter` / `Space`）：修改选中项
- `s`：保存并退出
- `q` / `Esc`：退出不保存

配置保存在 `~/.tao_tools/sertool/config.ini`（Windows 下即 `%USERPROFILE%\.tao_tools\sertool\config.ini`）。
每次 `connect` 成功后会自动记住本次端口与波特率，下次设置界面可见「上次端口」。

### 交互操作
连接成功后进入 TUI 界面：
- **上方区域**：实时显示设备串口发出的数据（支持 ANSI 颜色 / HEX 模式）
  - 文本模式：收到换行即出行；没有换行的数据在读超时（约 50ms）后整块显示，最后一个未完成行也会显示在末尾
  - HEX 模式：每行 16 字节、行首为 `0x%04x` 累计地址偏移（跨读块连续，断开/重连/切换模式后归零）
- **下方输入框**：打字输入，回车发送到设备
- **状态栏**：显示连接状态（绿色已连接 / 红色已断开）、本次连接累计接收字节数（`RX n B`）
- **快捷键**：
  - `↑` / `↓`：滚动查看历史数据
  - `PgUp` / `PgDn`：快速翻页
  - `鼠标滚轮`：滚动历史数据
  - `Enter`：发送输入框内容
  - `Ctrl+B`：切换波特率（在常见波特率列表中循环）
  - `Ctrl+H`：切换 HEX / 文本显示模式
  - `Ctrl+S`：切换 HEX / 文本发送模式（HEX 发送时输入 "FF A0 01" 发送原始字节）
  - `Ctrl+D`：断开 / 重连串口（不退出 TUI）
  - `Ctrl+E`：切换回车发送 / 回车换行
  - `Ctrl+L`：切换发送时追加 / 不追加 `\r\n`
  - `Ctrl+Enter`：强制发送（回车换行模式下使用）
  - `Esc` 或 `Ctrl+C`：退出
- **波特率**：`connect <端口>` 不带波特率时取 `sertool settings` 保存的值（默认 115200）；USB CDC ACM 设备波特率不影响数据传输，连接后也可用 Ctrl+B 切换
- **断线重连**：设备断开或拔插后自动检测，每 2 秒尝试重连

### 交互演示

```
┌─ COM7 @ 115200bps ────────────────┐  ← 绿框=已连接 / 红框=断开
│  I (708) esp_image: segment 4...  │
│  I (3762) TEST_AI: >>> [2]...     │  ← 设备输出（↑↓滚动）
│  <<< hello                        │  ← 发送回显
│                                    │
├─ 发送 ────────────────────────────┤
│ > hello world                     │  ← 专用输入框
├────────────────────────────────────┤
│ ✓ 已连接 COM7 @ 115200bps  ↑↓滚动  │  ← 状态栏（含 RX 累计字节数）
└────────────────────────────────────┘
```

## 更新历史

## 开发规范

通用规范见根目录 [AGENTS.md](../../AGENTS.md)，本工具特有约定：

- **双文件结构**：串口与 TUI 逻辑在 `src/main.rs`，配置读写与设置 TUI 在 `src/settings.rs`；按「参数解析 / 串口扫描 / 连接与收发 / TUI 渲染 / 设置」分段组织，新增功能前先补分区注释
- **线程模型**：接收线程独占串口读取并实时打印；主线程只负责键盘输入与串口写入 —— 遵循根规范的「交互模式约定」
- **TUI 依赖**：`ratatui` 0.29 + `crossterm` 0.28；退出必须恢复终端（`disable_raw_mode` + `LeaveAlternateScreen`），异常退出也要走同一收尾路径
- **串口**：波特率默认 115200，`connect` 可指定；Windows 串口名形如 `COM3`，Linux 形如 `/dev/ttyUSB0`
- **ESP32 兼容**：读取要容忍 ESP32 CDC-ACM 驱动差异，连接时自动置 DTR 让 ESP32 退出复位状态
- **接收管线**：增量 UTF-8 解码、无换行 pending、HEX 地址偏移集中在 `RxBuffer`（`src/main.rs`），与串口/TUI 解耦，改动这些纯逻辑必须补 `cargo test -p sertool` 单测；读超时 `READ_TIMEOUT`（50ms）同时是 pending 的 flush 阈值
