# blueinfo 开发计划

> 状态：进行中　最后更新：2026-11-21　版本基线：v1.1.0

## 1. 目标

桌面蓝牙调试与数据可视化：串口蓝牙（HC05/HC06）通信、实时曲线、参数下发、日志导出，带独立设置窗口供 toolhub 直达。

## 2. 非目标与分工边界

- **TUI 串口终端不做** → 归 [sertool](sertool.md)。
- **通用串口调试（无图形）不做**：本工具一切功能围绕图形界面与可视化。
- **不做跨工具共享代码**：与 sertool 的「串口参数配置」各自实现，字段与取值对齐即可（见第 3 节 P1）。

## 3. 候选功能

### P0 BLE 低功耗蓝牙拓展（btleplug）

- 验收：新增「BLE 模式」与现有串口模式并列可选；能扫描设备、连接、浏览 GATT 服务/特征、订阅通知；通知数据能进曲线与日志；断开可重连。
- 备注：接口按现有 `comm.rs` 思路抽象（独立线程 + channel 交给 GUI），不让 GUI 循环阻塞在 BLE 调用上。

### P1 截图保存

- 验收：曲线区可保存 PNG 到配置目录（`~/.tao_tools/blueinfo/`），文件名带时间；截图只含绘图区，不含整个窗口。

### P1 串口参数配置（数据位 / 停止位 / 校验位）

- 验收：设置窗口与连接面板可选数据位/停止位/校验位，连接时生效。
- **与 sertool 同源**：先用 [sertool](sertool.md) 定下参数模型与 `config` 字段名，本工具对齐；不共享代码（除非用户同意抽 crate）。

### P2 多语言界面切换

- 验收：中/英切换存配置，重启生效；至少覆盖菜单与设置项。

### P2 历史配置导入导出（跨设备）

- 验收：配置可导出为 JSON 文件并导入，导入前校验版本字段，失败给中文提示。

### P2 数据回放

- 验收：可加载已导出的日志按时间轴回放到曲线区，支持暂停/快进。

## 4. 版本规划

| 版本 | 内容 |
|---|---|
| v1.2.0 | P0 BLE 拓展 |
| v1.3.0 | P1 截图 + 串口参数配置 |
| v1.4.0 | P2 多语言 / 配置导入导出 / 数据回放 |

## 5. 风险与未决问题

- `btleplug` 在 Windows 走 WinRT，需要对应 feature 与系统蓝牙权限；与 `serialport` 的线程/句柄模型不同，需独立线程与状态机。
- BLE 与串口双模式切换时，曲线数据源要能平滑切换，避免环形队列被两路数据混写。
- 串口参数配置依赖 sertool 先落地模型，顺序不能反。
