# deskman - 桌面快捷方式分类整理器

版本: v4.0.0

## 简介

`deskman` 是 tao_tools 工具链中的桌面接管式整理工具：把桌面上的快捷方式、文件、文件夹收纳进深色玻璃分类面板（显示真实图标），桌面本身交给 deskman 管理。
平时面板安静地贴在桌面上、不抢焦点，任何窗口都能盖住它；`Ctrl+Alt+E` 随时进入编辑模式调整布局。**退出软件时桌面完整还原**（图标原位、原可见状态），状态落盘保证崩溃/强杀后也能自动恢复——绝不是一次性的。

## 使用方法

### 启动桌面常驻分类界面

```bash
cargo run -p deskman -- gui
```

首次启动会自动创建默认配置：

```text
%APPDATA%\.tao_tools\deskman\config.json
```

也可以用命令查看配置路径：

```bash
cargo run -p deskman -- config
```

### 界面操作

- **锁定模式（日常使用）**：桌面面板正常显示与点击，底部中央只有一个半透明迷你徽标，点击其中的"编辑"进入编辑模式。
- **编辑模式**：底部中央出现完整工具条：重新扫描 / 新建分类 / 锁定 / 设置 / 隐藏 / 退出。
  - 拖动面板任意空白处即可移动面板；拖动面板内图标可自由摆放（自由布局）。
  - 面板头部悬停显示"设置 / 收起"；收起后变成胶囊，点击"展开"恢复。
- **锁定模式下面板悬停**：右上出现"…"菜单（收起/展开、面板设置、进入编辑模式）。
- **点击图标**：直接打开目标（文件、文件夹、网页、命令或快捷方式）。

右下角托盘图标提供快捷菜单，可直接执行：

- 显示主界面
- 隐藏主界面
- 扫描桌面
- 打开设置
- 切换锁定
- 退出 deskman

### 扫描桌面

```bash
cargo run -p deskman -- scan
```

扫描来源：

- `%USERPROFILE%\Desktop`
- `C:\Users\Public\Desktop`

扫描到的 `.lnk`、`.url`、文件和文件夹会进入"未分类"面板，重复路径不会重复导入。

### 设置窗口

点击编辑模式工具条中的"设置"（或托盘菜单"打开设置"）：

- **扫描**：用户/公共桌面开关、启动时导入未分类、立即扫描桌面。
- **面板**：不透明度滑块、置顶开关、工作区大小。
- **分类**：新建分类，每个分类可跳转"设置"进入面板设置窗口（名称、宽高、图标尺寸、排列方式、锁定位置/尺寸、添加/删除项目、删除分类）。

### 窗口管理

窗口管理是保留的高级命令：

```bash
# 列出可见窗口
cargo run -p deskman -- window list

# 查找窗口
cargo run -p deskman -- window find Chrome

# 聚焦窗口
cargo run -p deskman -- window focus Chrome

# 移动并调整窗口
cargo run -p deskman -- window move Chrome 100 80 1280 720

# 设置置顶 / 取消置顶
cargo run -p deskman -- window topmost Chrome on
cargo run -p deskman -- window topmost Chrome off

# 最小化 / 恢复
cargo run -p deskman -- window minimize Chrome
cargo run -p deskman -- window restore Chrome
```

### 工具管理

```bash
# 列出工具
cargo run -p deskman -- tools list

# 构建工具
cargo run -p deskman -- tools build sertool

# 安装工具
cargo run -p deskman -- tools install sertool

# 输出 README 路径
cargo run -p deskman -- tools readme sertool
```

安装后可直接使用：

```bash
cargo install --path deskman
deskman gui
deskman config
deskman scan
```
